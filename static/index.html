使用注意事项
① 冻结是什么
冻结 = 你确认"机器切的框对了"，同时落地确认页上的手动修正，并打开改数的总闸门。
不冻结 = 只读模式：问答 / 表格解读 / 勾稽核对随便用，改数一律被拦，文件绝对安全。
② 问答怎么问
"这个表格 / 当前表格" 指你现在看的 sheet；"整个文件 / 这些表什么关系" 问全簿。
追问（如"那为什么这么算"）自动带最近 4 轮上下文；点 🗑 新对话 清空重来。
③ 改数怎么写
改数不认"当前页面"，按 sheet 关键词 + 行键 + 列名在全簿定位——指令里带上 sheet 名最稳
（例："把销售部1月的差旅费金额加3000"）。命中多行会被拦下让你说清。
流程：语义解析 → 硬校验 → diff 预览（旧值→新值） → 你确认 → 写入（自动备份，可撤销）。上传副本模式下写入只进副本，成品需点页眉「📥 导出改后文件」下载。
④ 区块按钮的效果（冻结后生效）
按钮效果
切为 🟨文本/批注这块退出问答与改数（数据仍在文件里，只是不当表用）
切为 ⬜忽略同上：退出问答 + 拒绝改数
切为 🟥混合待复核隔离：禁改数、不进问答，直到定型成数据表或文本
🔒只读仅本应用内只读：工具禁止改这块（可正常问答）。文件本身不变——Excel/WPS 里仍可编辑，文件属性也不变
🔓可写解除上面的应用内只读
📐调整范围框盖小了/劈开了/圈多了 → 选中块后直接拖蓝框的边/角（或点「📐 调整范围」后拖橙框/填数字/点两下）；表头树和记录会在新范围内由机器自动重新识别，随冻结生效。与其他未忽略区块重叠会被拦截（先把重叠块设为忽略）
误触保护：修改点冻结才生效（顶部有"待提交 N 处"提示）；冻结前刷新页面 = 全部撤销；每块可 ↩ 撤销本块修改；冻结后切错了，再切一次并重新冻结即可。
注：引擎判为文本的黄块切"数据表"仅作视觉标记（无列结构，不参与问答）。
⑤ 文件被改动后
自己用工具改的数 → 重开无缝续用（冻结保持）。
别人改了数值 → 重新拖入，绿条提示"数值已刷新"，冻结仍有效，不用重确认。
结构变了（增删表/改表头） → 重新拖入，橙条列出变化清单，未变块的标记自动保留，复核后重新冻结。
⑥ 打开文件与副本
三种打开：📂 路径（Shift 右键复制文件地址粘贴——写回原文件，推荐）； 上传副本（分析体验——改动只写副本，页眉出现〔副本〕徽记）； 拖文件到桌面应用图标 / 拖入桌面窗口（=写回原文件）；网页页面里拖入（=上传副本）。
副本模式的成品 = 点页眉「📥 导出改后文件」下载的文件——原上传的文件永远不含你的改动，别把它发给别人。
改数前会重过一遍全部校验；表头、汇总行、公式格、忽略区块永远不会被写入。所有人工标记（类型/只读/词典/行内备注挂接）只存在于本工具的镜像里，永不修改你的文件（改数指令除外）。
怎么用：蓝框=表格（问答和改数都发生在蓝框里，只需扫一眼框得对不对）； 黄虚线=标题/备注（不当表格处理，不用管它；标了「表内批注」的是表格中间夹的一行备注，正常现象）； 红框=机器拿不准（最好点开看一眼）。 没问题 → 点右上「检查无误，冻结」→ 去底部工作台。框不对 → 点色块改类型；范围不对 → 选中后直接拖蓝框的边/角调整，表头和列名会在新范围里自动重新识别。
